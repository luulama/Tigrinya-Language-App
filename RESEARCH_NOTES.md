# Research and design decisions

Reviewed 20 November 2026. These are design inputs, not evidence that this unreviewed prototype improves Tigrinya learning. No competitor assets, language content, characters or screen layouts were copied.

## Decisions made from the evidence and the available content

The subsequent [Fidäl writing revision](FIDAL_WRITING.md) adds Tigrinya-specific Harvard/UK/Unicode source checks, vowel-order labels, real freehand/Unicode input and gated teacher data. It supersedes the earlier visual-only writing scope below; missing native stroke/audio evidence is still explicit.

**Scope:** Keep two units. Unit 1 offers three complete seven-form visual-family activities; each follows introduction, guided comparison, recap, a demonstrated difference-spotting task, an independent check with optional support, and a result/next step. Unit 2 offers complete activities using up to three existing picture-word candidates, with Look → Make it → Find it → pairs → recap → cumulative word check → outcome. A single-picture activity has a guided check and is explicitly counted as supported, not an independent answer.

**Appropriate challenge:** A Unit 1 final check compares two identical forms and one different form, using only the current introduced family. It measures visual discrimination, not sound knowledge or spelling recall. Unit 2's cumulative check uses only the activity's taught words and never places same-art alternative headwords in competition. Wrong answers show the appropriate model and allow retry; supported items return once later with the model hidden again. A supported first encounter remains reported as supported even if the later attempt succeeds without help.

**No invented curriculum:** The project has no approved audio, example dialogues, grammar sequence, cultural notes or fully approved vocabulary. Those features are excluded. T/M remain complete shape activities without filler picture words. The existing 142-entry source bank, its senses and provenance, and the 32 picture candidates remain unchanged and pending native review.

**Time and continuity:** About 3–5 minutes is an unvalidated planning estimate per small activity, not a timer or a promised duration. Existing in-memory privacy behavior remains: no cross-day scheduling or persistence. Navigating within a unit supports pause/resume; reloading or normal cross-unit navigation does not transfer activity state.

**Validation:** Automated tests exercise the full journeys, corrections, recurrence and supported-result accounting, plus source integrity, build parity and structural accessibility checks. Browser control timed out, so rendered layout, real keyboard/VoiceOver behavior and child usability remain unverified. Native Tigrinya review and licensed word/direction recordings remain release requirements.
